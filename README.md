# DP-700-Analyze-data-with-Apache-Spark-in-Fabric
In this lab you will ingest data into the Fabric lakehouse and use PySpark to read and analyze the data.

# 🔹 Step 1: Open the Microsoft Fabric environment
Go to the Microsoft Fabric portal: https://app.fabric.microsoft.com

Sign in or start a free trial.

In the top-left menu, select Workspaces and create a new workspace (e.g., LakehouseLab).

# 🔹 Step 2: Create a Lakehouse
Inside your workspace, click + New > Lakehouse.

Name your lakehouse (e.g., SalesLakehouse).

Once the lakehouse opens:

Go to the “Files” tab.

Upload a CSV file (e.g., sales data) from your computer.

Optionally, convert the uploaded file into a table using “New table.”

# 🔹 Step 3: Create a notebook and start the Spark session
In the same lakehouse, click + New > Notebook.

Name the notebook (e.g., SalesAnalysis).

In the notebook, select the Spark (PySpark) kernel.

Start the Spark session with a simple command

# 🔹 Step 6: Visualize the data
Use the display(df) function to access built-in visualizations.

Choose a visualization type, such as:

Bar chart to show sales by country

Pie chart to show distribution by category

You can easily switch between visualization types using the dropdown menu.

# 🔹 Step 7: Save and share your notebook
Click Save in the top menu to store your notebook in the workspace.

Optionally, share the notebook with team members or export it.

This notebook can later be connected to Power BI for reporting.

# 🎓 Learning Outcomes
## 💡   🎯 
Learned to create and navigate workspaces, lakehouses, and notebooks in Microsoft Fabric.

Uploaded local data files into a lakehouse for analysis.
